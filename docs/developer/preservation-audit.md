# Documentation preservation audit

This checklist implements the approved proposal's traceability matrix. It uses
finer paragraph/code/table ranges where a source section contains independent
topics. Source line numbers refer to the pre-migration working tree, including
the preexisting README wording, not to compatibility pages now at those paths.

Every nonblank line of the original README and all 15 original docs Markdown
files has a destination. The four original DOT/SVG assets remain at the same
paths and were regenerated together. Scientific source, packaging, root DESIGN,
CONTRIBUTING, visualization files and preexisting configuration edits are protected
by baseline hashes. No untracked scientific configuration was staged or published.

## Review method and findings

Before retirement, a normalized paragraph comparison of copied ranges found
437 of 457 substantive blocks unchanged apart from whitespace/headings/link targets.
The remaining 20 blocks were reviewed: coordinate equations/policy, diagnostics
truth requirement, structure-function scope, unavailable script labeling,
architecture consolidation/count, extension wording, onboarding dependencies,
overlay count and navigation. No unexplained scientific-text difference remained.
Subsequent local equation SVGs retain all original TeX in source blocks and
`assets/equations/sources.json`; their rendering does not change the equations.

All original historical numerical tables, values and warning descriptions remain.
Affine and quadratic experiments retain separate full setups, tables, conditions,
validation reports and provenance; their shared fixture description is intentionally
repeated to keep each historical experiment self-contained. These results were
not rerun. See [scientific review](scientific-review.md) for unresolved physical
questions and [examples](../examples/index.md) for release availability.

| Legacy paths and anchors | Navigation-only compatibility pages retain original heading anchors; no second scientific authority. |
| Out-of-scope documents | Unchanged and linked with explicit ownership; remaining duplication recorded for later review. |

## Source-topic checklist

“Retained” means destination coverage, not independent scientific confirmation.
Ranges containing corrected prose are covered by the explicit dispositions above.
Tables, code blocks and equations are treated as units. Headings provide context;
all parameter families and caveats within a range migrate together.
